Projeto com o objetivo de criar uma extensão para o Google Chrome usando apenas html, css e JavaScript.

A extensão em si é bem simples, basta copiar uma url de imagem qualquer e adicionar no form e todas as imagens de qualquer site é mudado para a imagem escolhida.

Para usar basta baixar o código e seguir o caminho no navegador Google Chrome: extensões => gerenciar extensões => ativa modo desenvolvedor => carregar sem compactação a pasta com o código.
